# GearShift Auto Parts

A responsive automotive spare-parts e-commerce front-end built with HTML5, CSS3 and Vanilla JavaScript.

## Files

- `index.html` — page structure, catalog, cart drawer and modals
- `styles.css` — dark automotive theme, layout and responsive styles
- `products.js` — mock product data and Unsplash image URLs
- `app.js` — search, filtering, authentication, cart and checkout logic

## Run

No build step is required.

1. Extract the project.
2. Open `index.html` in a modern browser.
3. Internet access is recommended because product images use Unsplash URLs.

## Demo behavior

Authentication, cart persistence and checkout are simulated with browser `localStorage`. No real payment is processed and no backend/database is included.
